# VPNSky 1.0.0 — First Release

**Release date:** 2026-10-19
**Platform:** Android 7.0+ (API 24)
**Package:** `com.wingsheep.vpnsky`
**Version:** `1.0.0` (versionCode `56742602`)

VPNSky is a WireGuard-based VPN client with a live flight-deck interface. This is the first public
release: connect to the configured VPNSky server, watch the tunnel come up, and see what it is
actually doing.

## Highlights

- **One-tap WireGuard connection.** Connect and disconnect from a single control, with explicit
  connecting, permission, connected, disconnecting, and error states — no silent spinners.
- **Clean service lifecycle.** The VPN service starts only when a connection is requested and stops
  as soon as the tunnel goes down, so an idle or disconnected app leaves no VPN service running in
  the background.
- **Per-install tunnel identity.** A Curve25519 keypair is generated on the device, stored in
  app-private storage, and registered with the VPNSky registry. Each install gets its own tunnel
  address; no private key or pre-shared key ships in the APK.
- **Live connection dashboard.** See the assigned tunnel address, server location when the operator
  provides one (or it can be resolved from the endpoint), and real-time downlink/uplink counters.
- **Flight scene.** The rocket lifts off while the tunnel is being established, holds orbit while
  connected, and returns to base on disconnect — a visual state indicator rather than another
  spinner.
- **About & privacy.** In-app information about the engine, protocol, and privacy posture.
- **No advertising or analytics SDKs.** Connection statistics stay on the device.

## Under the hood

- WireGuard via the official `com.wireguard.android:tunnel` library and `GoBackend`.
- React Native 0.86 with the new architecture; the tunnel runs in a thin Kotlin module.
- All blocking tunnel work is confined to one background thread, separate from the UI and the
  React Native bridge.
- Remote configuration (server endpoint, public key, DNS, allowed IPs, keepalive, registry token)
  is delivered through Firebase Remote Config, with offline-safe defaults embedded.
- Release builds are R8-minified and shipped as an Android App Bundle, so Play delivers only the
  ABI and resources each device needs.

## Privacy and security

- The client private key is generated on-device and kept in app-private storage. It is never
  bundled, logged, or sent to the registry — only the public key is registered.
- WireGuard traffic is handled by the operator-configured server. The app contains no ad or
  analytics SDK.
- The default routing policy is full-tunnel (`0.0.0.0/0`, `::/0`); operators may narrow it through
  Remote Config.
- Release artifacts are signed with the VPNSky upload key:
  `SHA-256 2C:08:98:CE:62:3C:8A:F7:3A:6D:C4:1C:33:F6:B9:24:3E:44:5C:7C:20:29:27:05:A1:34:93:76:11:66:2E:B5`.

## Requirements

- Android 7.0 (API 24) or newer.
- A configured VPNSky backend and Remote Config values.
- Network access for configuration, registration, and the tunnel itself.
- Android's VPN permission on first connect.

## Installation

- **Google Play:** join the internal testing track for `com.wingsheep.vpnsky`.
- **APK:** sideload `app-release.apk` (Android may ask you to allow installs from your browser or
  file manager).

## Known limitations

- Android only; the iOS target is a shell with no VPN implementation.
- One configured server per build — there is no in-app server picker yet.
- No auto-connect on boot and no split-tunneling UI in this release.
- The interface is English-only.
